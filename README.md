# HBR Account Export

Standalone Windows x64 export mod which exports official account data to a lilypad-compatible file.

## Usage

1. Download the ZIP from [Releases](https://github.com/SeraphArchive/account-export/releases)
2. Unzip to your game folder
3. Launch game and wait for it to export and automatically close
4. Check `account-export/exports/lilypad-export-*.json`
5. Restore or remove `version.dll` before playing

Note that this mod cannot be used along with clientpatch, which is intended. For exporting data from a lilypad server,
use the web portal.
